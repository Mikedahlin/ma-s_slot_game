# Slot wheel image requirements

Put your custom images in this folder using these exact file names:

- cherry.svg (or cherry.png)
- bell.svg (or bell.png)
- diamond.svg (or diamond.png)
- seven.svg (or seven.png)
- star.svg (or star.png)

Recommended size:

- 512 x 512 pixels
- transparent background
- centered symbol with clear edges

If you use PNG instead of SVG, keep the same base names and update `SlotMachine.tsx` paths.
