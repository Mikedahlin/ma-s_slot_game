Add your own final image files in this folder using these exact names.

Required symbol images (square preferred):
- seven.jpg
- diamond.jpg
- coin.jpg
- cherry.jpg
- clover.jpg
- star.jpg
- bonus.jpg

Required bonus banner images (wide landscape):
- bonus-pick.jpg
- bonus-wheel.jpg
- bonus-match.jpg

Recommended export specs:
- Symbols: JPG, 1024x1024, high quality, no text overlays.
- Bonus banners: JPG, 1920x720 (or 1600x600), high quality.
- Keep colors rich and realistic (Vegas style), avoid cartoon filters.
- Avoid tiny details or long text in-image; symbols must read clearly at small size.

Important:
- Filenames must match exactly (including dashes and lowercase).
- If a file is missing, the game will show fallback text/icon in that slot.
