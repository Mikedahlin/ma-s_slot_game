# Audio files used by the game

This folder is already wired to these sound events:

- button.wav -> button tap
- spin.wav -> spin start
- reel-stop.wav -> reel settle click
- win-small.wav -> small win stinger
- win-big.wav -> big win stinger
- win-mega.wav -> mega win stinger
- bonus-trigger.wav -> bonus round trigger stinger
- mission-complete.wav -> mission completion
- ambience-loop.wav -> background lounge loop

You can replace any file with your own WAV/MP3, but keep the same file name.
